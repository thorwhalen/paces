paces.render

Render a StepDocument into learning material.

The renderer depends on the document and resolve() — never on the analyser. v1 ships one renderer: a self-contained HTML practice page (steps, counts, captions, deep links into the sources, and — when the document has a metric grid — a count-along transport that paces you through the routine, which is the behaviour the package is named after).

paces.render.ROLE_LABELS = {'closeup': 'close-up', 'instruction': 'breakdown', 'performance': 'run-through'}

Span roles shown as deep links, in display order.

paces.render.render_html(doc: StepDocument) → str[source]

The practice page: steps, counts, deep links, captions, and (with a grid) the count-along transport. Self-contained; media-free by design — derived clips arrive via ArtifactRef when the media layer exists.
